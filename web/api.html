📡 API Reference

Available endpoints (server must be running).

POST /api/process
Process a data file. Body: { inputFile, outputFile, patterns }
POST /api/assets
List and process assets folder. Body: { assetsPath, extensions }
POST /api/search
Search within a session. Body: { sessionId, term, fields }
POST /api/export
Export data. Body: { sessionId, format, filename }
POST /api/transform
Transform data. Body: { data, operation, options }
POST /api/aggregate
Aggregate data. Body: { data, operation, key }
POST /api/validate
Validate data against rules. Body: { data, rules }
GET /health
Health check – returns server status.
WS ws://localhost:8080
WebSocket for real‑time updates. Send { type: 'get:status' }
