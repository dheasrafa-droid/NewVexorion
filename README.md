# NewVexorion

A high-performance, fluent JavaScript data processing, transformation, validation, and asset pipeline library.

**Author:** Prasetyo Bayu Widodo  
**Repository:** [https://github.com/dheasrafa-droid/NewVexorion](https://github.com/dheasrafa-droid/NewVexorion)  
**Live Demo:** [https://new-vexorion-git-main-ercs-projects-09b1de49.vercel.app/](https://new-vexorion-git-main-ercs-projects-09b1de49.vercel.app/)

---

## 🌟 Key Features

- **Fluent Method Chaining:** Intuitive `.read().filter().save()` interfaces.
- **Stream Processing:** Process gigabyte-scale datasets with low memory footprints using Node streams.
- **CSV Parsing & Export:** Convert raw lines into structured objects, and export to CSV, JSON, and formatted HTML tables.
- **Asset Processing Engine:** Scan and parse `.csv`, `.json`, `.xml`, `.html`, `.txt`, `.md`, `.log`, and `.yml`.
- **Reactive State & Attribute System:** Three.js-inspired `Attribute` and `AttributeManager` with dirty checking.
- **Event Bus:** Flexible `EventDispatcher` supporting `.on()`, `.once()`, `.off()`, and `.emit()`.
- **Built-in Interactive Web Viewers:** Standard and Enhanced data viewers for real-time filtering, analytics, and client-side exporting.

## 🚀 Getting Started

### Installation
```bash
npm install
```

### Running Examples
```bash
# Run basic processor
npm run start

# Run enhanced processor with CSV parsing & search
npm run enhanced

# Run full pipeline demonstration
npm run full

# Run asset loader & processor
npm run assets

# Run reactive attribute manager & event system
npm run attributes
```

### Running Tests
```bash
npm test
npm run test:full
```
